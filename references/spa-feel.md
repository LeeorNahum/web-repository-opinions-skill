# SPA Feel

A signed-in app should feel like one continuous application, not a series of full page loads, while keeping real URLs.

Achieve the feel with:

- An app shell that stays mounted across navigation
- Navigation between app routes without a document load
- Secondary flows in a drawer, sheet, or dialog over the current view
- A persistent element where it fits the product, such as a mini-player or active-object bar

App feel is a navigation and state concern, never a reason to give up addressable routes.
