# Web Repository Opinions

An opinionated, modular skill for building TypeScript web products and any repo built on web technology. It encodes durable preferences so web surfaces get built faster and more consistently across projects.

The opinions are paradigm-named and provider-stated: sections are named for what they do, and the default tool inside each is a swappable pick.

## Layout

- `SKILL.md` is the spine: thesis, default stack, the reference-loading map, core non-negotiables, and the audit procedure.
- `references/` holds one single concept per file, loaded on demand.
- `assets/` holds copyable starter files for a target repo.
- `AGENTS.md` is the editing and maintenance contract for this skill.

## Coverage

Architecture and identity, rendering and surfaces, URL state, runtime and deployment, auth and data ownership, external integrations, storage and jobs, search, product interaction, responsive UI, billing and administration, and release readiness.

## Use

Auto-invokes on web-technology repo work. Read `SKILL.md` first, then load only the references the task needs.
