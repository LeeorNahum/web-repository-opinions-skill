# Pellora

Pellora is a shared shopping list app at pellora.app. People sign in, keep lists with their household, and can connect an AI agent through Pellora's MCP connector so the agent can add items for them. There is a free plan and a paid plan billed monthly.

Dana Whitlock builds and runs Pellora on her own. There is no company yet.

## The public site today

- Pages: `/` (home), `/pricing`, `/terms`, `/privacy`.
- Footer: Pricing, Privacy, Terms.
