# Tallyho

Tallyho is a free tip and bill-splitting calculator at tallyho.page. It is a single static page: no accounts, no sign-in, no payments, and nothing people type is sent anywhere. The site uses a privacy-friendly analytics script that records page views, and the host keeps request logs.

Priya Raman made it and runs it as a hobby.

## The site today

- Pages: `/` only.
- Footer: just "Tallyho".
