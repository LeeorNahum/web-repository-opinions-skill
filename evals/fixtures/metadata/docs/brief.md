# Tessel

Tessel lets people publish interactive HTML pages that they or their AI agents write. Each page has an address on Tessel. Tessel serves its own wrapper page at that address, with a slim toolbar, and the person's HTML runs inside it.

## Visibility

- Public: anyone can open it, and it is indexed.
- Unlisted: anyone with the link can open it, and it is not indexed.
- Private: only invited members can open it, after signing in.

## Decided

- A simple page is one HTML file. Nobody should have to write a separate manifest or make a preview image to publish.
- Pages can save data through the Tessel runtime, for example votes on a poll page.
